# COMP1818_Airline_Sentiment

## 1. Overview
   This Project uses AI to detect positive, negative, and neutral sentiment in airline customer reviews and understand brand perception.

## 2. How To Run
The experiments were run in Google Colab.

### 1. Download repository files: 
Download the Kaggle dataset, COMP1818_Airline_Sentiment_FinalDraft.ipynb, cleaned_all.cvs and final_test.json from the repository.

### 2. Open in Google Colab:
Upload COMP1818_Airline_Sentiment_FinalDraft.ipynb to Google Colab and change the runtime to T4 GPU.

### 3. Dataset File:
Upload cleaned_all.csv and final_test.json to (/content/drive/MyDrive/), ensuring the file paths in the notebook match where you saved them.

### 4. Run
Run all to install the required libraries, load the data, train and evaluate the model, and generate brand_perception.png and test_predictions.csv.

###5. View Output:
Evaluation metrics and plots are printed in the notebook output, and final predictions are saved to test_predictions.csv.
